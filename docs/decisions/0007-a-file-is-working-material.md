# 0007: A file that travels is working material

## Decided

A TARA taken in from a file is always a new draft. The file is read first and what it would bring is shown; nothing is stored until the person says so. Signatures, confirmed reviews, the arrangement of the diagram and the history do not come with a file. Nothing that is here is replaced: a TARA that would collide with one that exists gets a number and a title of its own.

To move a TARA exactly as it is, its folder is copied.

## Why

- **A signature and a review are statements by people.** A file can claim that someone reviewed or signed; it cannot show it. Carrying such claims in would let an assessment arrive "approved" with nobody here having looked at it. The references of the reviews do travel, so the reviewer knows where to look, and confirming again is one step per record.
- **Seeing before storing.** A file from elsewhere may be something other than expected, or may collide with what is here. The person should know before, not find out after.
- **A number means one thing.** If an import could replace a TARA, or sit beside it under the same document number and revision, a reference to that number would no longer say which assessment is meant.
- **An arrangement is a view.** Where someone placed the boxes of a diagram is how they chose to look at the records, not what the assessment says. A file carries the elements, the flows, the boundaries and what is inside them, and the diagram is drawn from those. Because the tool can always draw the diagram from the records alone, nothing is lost that cannot be made again in a minute.

## What it costs

- After an import, each review has to be confirmed again, and the diagram arranged again if its arrangement mattered.
- There are two ways to move a TARA, and people have to know which they want. The Export screen and the documentation say so where the choice is made.
